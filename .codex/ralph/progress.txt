## Codebase Patterns
- DocTology distributes exactly three self-contained skills; do not create a fourth product or root runtime.
- `llm-wiki-bootstrap` owns generated optional SQLite retrieval helpers; `llm-wiki-loop` owns semantic judgment, coverage, and completion gates.
- `raw/**/*.md` and `wiki/**/*.md` remain canonical. SQLite indexes and structure trees are disposable derived candidates.
- Raw search reopens canonical byte spans and keeps cheap stat status, unchecked discovery, and exact doctor as separate lifecycle levels.
- Generated helper scripts live beside `llm-wiki-bootstrap` and are copied through `generated_helper_script()`.
- Multi-source seal keeps semantic drafts outside `wiki/`, journals `refreshing` before one retrieval refresh, journals prepared run payloads before live replacement, and blocks any out-of-journal run mutation.
- `.ouroboros/` contains PM runtime artifacts from this task and is not product source.
