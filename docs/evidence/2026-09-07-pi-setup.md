# Pi manual preparation help

now offers only static installation, /login, /model, and manual smoke-check
instructions from the topbar/sidebar and missing-Pi prompt. It distinguishes
missing workspace from missing executable. Existing RPC invocation, credential
ownership, and optional invocation model overrides are unchanged.

model preference persistence, and a discovery adapter. That management layer
