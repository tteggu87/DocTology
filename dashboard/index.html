Pi 사용 준비

이 대시보드는 설치와 설정이 끝난 Pi를 호출합니다. Pi 준비는 터미널에서 한 번만 해 주세요.

  1. 설치

    Node.js LTS를 설치하세요. Windows는 Git for Windows도 필요합니다. PowerShell 또는 터미널에서 실행합니다.

    npm install -g --ignore-scripts @earendil-works/pi-coding-agent
  2. 로그인·모델 설정

    터미널에서 pi를 실행하고, /login으로 제공자 로그인 또는 API 키 등록을 마친 뒤 /model로 모델을 선택하세요.

  3. 동작 확인

    같은 터미널에서 Pi에 짧은 질문을 보내 정상 응답을 확인하세요. 그 환경에서 Studio를 실행하거나 재시작한 뒤 위키를 연결하면 됩니다.

Pi의 인증과 기본 모델을 그대로 사용합니다. 대시보드의 모델 입력칸은 비워 두어도 됩니다. 설치 후에도 Pi를 못 찾으면 Studio를 실행하는 계정과 PATH를 확인하세요.

설정 초기화




현재 워크스페이스의 폴더 감시와 자동 실행을 끄고, 감시 경로를 원문 폴더(raw)로 돌립니다. 이 창의 모델 선택·병렬 준비 수·검색 필터·그래프 배율도 기본값으로 바꿉니다.


위키 연결과 파일, 대화·작업·대기열 기록, Pi 로그인과 기본 모델은 유지합니다. 진행 중인 작업과 이미 요청한 수동 실행은 취소하지 않습니다. 예시·프로젝트 문서 모드에서는 화면 설정만 초기화합니다.
