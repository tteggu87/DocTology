# Architecture Decision Records

Canonical durable decisions live here. Add one ADR when the repository makes a
structural, authority, compatibility, storage, security, or runtime decision
that future maintainers must not repeatedly rediscover.

Use `ADR.template.md`. Keep decision status separate from implementation
status, link implementation and evidence when claimed, and preserve superseded
ADRs instead of rewriting history.
