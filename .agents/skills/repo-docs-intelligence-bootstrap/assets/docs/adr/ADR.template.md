# ADR-XXXX: Decision title

## Context

State the durable structural, authority, or compatibility problem and cite the current code, tests, or canonical docs that establish it.

## Decision

Record the chosen rule and its boundary. This ADR is the canonical decision record; derived wiki summaries must link back here.

## Implementation
